Coaching and training · IRD programme · Ben & Archie support

The situation

Research project owners need to identify intended users, potential applications, assumptions to test and resources for implementation. A group programme should allow each participant to develop their own project while learning from others.

Our contribution

For an international IRD programme, Ben & Archie structured a learning journey and collaborative workspace for six projects. Led by Arthur Mossa and Paula Fajardo, the support brings together user understanding, ideation, hypothesis testing and operating-model tools. Shared resources support preparation, retain the work and enable exercises between sessions.

The documented outcome

A common working framework and project resources were prepared: use cases, user journeys, tests and implementation steps. The final programme review remains to be consolidated. The available resources provide a foundation for support; each project’s progress must be assessed separately.

Supporting a group of entrepreneurs or researchers? We design a programme connecting shared learning with practical work on each project.
